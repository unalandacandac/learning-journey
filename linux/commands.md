LINUX DERS 3 - DOSYA VE DIZIN YONETIMI

pwd       → Nerede olduğumu gösterir
ls        → Dosya ve klasörleri gösterir
ls -l     → Dosyaları ayrıntılı gösterir
cd X      → X klasörüne girer
cd ..     → Bir üst klasöre çıkar
cd /home/backdoor-future → Home dizinine gider
cd ~      → Home dizinine gider
.         → Bulunduğum dizin
..        → Bir üst dizin
~         → Home dizini
touch X   → Boş dosya oluşturur
mkdir X   → Klasör oluşturur
rm X      → Dosya siler
